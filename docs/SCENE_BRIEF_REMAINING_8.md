# 残り8ゲートの絵 — 生成用の材料

既にある7枚（Fezouata / Kem Kem / Dinosaur Park / Hell Creek / Nemegt / Maevarano /
Western Interior）と同じ体裁で作るための一式。

**全部の学名をPBDBの記録と突き合わせ済み。** 分類・科・生息環境・生活様式もPBDBから引いて、
「何として描くか」を各行に書いてある。Maevaranoで *Lavanify miolaka*（哺乳類）を魚として
描いてしまった事故を繰り返さないため、**名前だけでなく「それが何か」を必ず読んでから描く**。

---

## 共通（7枚と揃える）

- 横長（16:9前後）。左上にゲート名を英語で1行、細い罫線
- 学名はイタリックで対象のそばに置く。**日本語や説明文は焼き込まない**（アプリ側が持つ）
- 下部の解説帯は入れない
- 水がある世界は、水面で上下に割る構図
- 光は古緯度に合わせる。低緯度＝高く硬い光、高緯度＝低く柔らかい光

## 1. Chinle

- **タイトル**: `Chinle`
- **時代**: 約217 Ma（三畳紀後期） / **古緯度 12.6N** — ほぼ熱帯
- **環境**: 陸（氾濫原・河道）。乾季と雨季のある川
- **一言**: 恐竜がまだ主役でない、川と湖

| 学名 | 何か | どこに |
|---|---|---|
| *Coelophysis bauri* | 小型の獣脚類（コエロフィシス科）。細身・二足 | 陸 |
| *Typothorax coccinarum* | アエトサウルス（ステゴノレピス科）。装甲した四足の主竜類。恐竜ではない | 陸 |
| *Machaeroprosopus buceros* | フィトサウルス（パラスクス科）。ワニに似るがワニではない。鼻孔が目の前 | 水辺 |
| *Anaschisma browni* | 大型の分椎目両生類（メトポサウルス科）。平たい頭のサンショウウオ的な姿 | 水中・水辺 |
| *Chinlea sorenseni* | シーラカンス類（マウソニア科）の魚 | 水中 |

**描いてはいけない**: *Zamites powelli* は動物ではなく**ベネチテス類の葉**（PBDB: form taxon）。
背景の植生として描くのは可。

- **一言**: 巨大な竜脚類が歩いた氾濫原

| 学名 | 何か | どこに |

## 3. Green River

- **タイトル**: `Green River`
- **時代**: 約49 Ma（始新世前期） / **古緯度 43.6N**
- **環境**: 大きな湖（lacustrine - large、101件）
- **一言**: 亜熱帯の湖と、そこへ落ちた無数の虫

**この1枚だけ主役が虫**。この範囲の記録は297種すべて昆虫で、有名な魚は300km北にあるため
「同じ場所」の枠から外れる。**魚は描かない。**

| 学名 | 何か | どこに |
|---|---|---|
| *Archimyrmex rostratus* | 大型のアリ（アリ科）。長い脚 | 岸・空中 |
| *Eoformica pinguis* | アリ（アリ科）。この層で最多（15件） | 岸 |
| *Eotetrix unicornis* | ヒシバッタ類（ヒシバッタ科）。小さく角ばった体 | 岸 |
| *Ectobius kohlsi* | ゴキブリ（チャバネゴキブリ科）。平たい体 | 岸 |
| *Cuterebra ascarides* | ヒツジバエ科のハエ。ずんぐりした毛深いハエ | 空中 |

**構図の案**: 水面で上下に割る。上は湖岸の植生と飛ぶ虫。下は静かな湖水と、
沈んでいく虫、細く縞になった湖底の泥。この層の化石はそうやってできている。

## 4. Šárka

- **タイトル**: `Sarka`（ハーチェクなしで統一。アプリ側は「シャルカ」）
- **時代**: 約466 Ma（オルドビス紀中期） / **古緯度 -56.1N** — 高緯度の冷たい海
- **環境**: 沖合の海底（offshore）
- **一言**: 泥の海底に降り積もった、殻の群れ

暗く冷たい水。光は上から弱く差す程度。

| 学名 | 何か | どこに |
|---|---|---|
| *Lesueurilla prima* | 巻貝（レスエリラ科）。海底を這う | 海底 |
| *Ribeiria apusoides* | 喙殻類。二枚貝に似るが別の絶滅群。半分泥に埋まる | 海底（半潜没） |
| *Babinka prima* | 二枚貝（バビンカ科）。泥に潜る | 海底（潜没） |
| *Sagittacystis prima* | 柄海果類（棘皮動物）。左右非対称の奇妙な体に1本の腕 | 海底 |
| *Plasiacystis mobilis* | ソルタ類（棘皮動物）。同じく非対称 | 海底 |

**注意**: *Lesueurilla prima* は**Fezouataの絵にも描かれている同じ種**。
2枚で姿を揃える（Fezouataの絵ではキャストに入っているが未描画なので、こちらが初出）。

## 5. Elliot

- **タイトル**: `Elliot`
- **時代**: 約214 Ma（三畳紀後期） / **古緯度 -49.1N**
- **環境**: 陸（乾いた氾濫原）
- **一言**: 大型化が始まったころの、乾いた氾濫原

| 学名 | 何か | どこに |
|---|---|---|
| *Melanorosaurus readi* | 初期の大型竜脚形類。四足寄り、首は中くらい | 陸 |
| *Eucnemesaurus fortis* | 竜脚形類（リオハサウルス科）。がっしりした体 | 陸 |
| *Blikanasaurus cromptoni* | 竜脚形類。太く頑丈な後肢が特徴 | 陸 |
| *Plateosauravus cullingworthi* | プラテオサウルス科の竜脚形類。二足も取れる | 陸 |
| *Scalenodontoides macrodontes* | **トラヴェルソドン科のキノドン**（哺乳類につながる単弓類）。毛のある四足獣として | 陸 |

**PBDBの分類が間違っている行がある**: *Scalenodontoides macrodontes* のclassは
`Osteichthyes`（硬骨魚）と出るが、科は Traversodontidae で**魚ではない**。魚として描かないこと。

**描いてはいけない（すべて足跡の学名）**: *Pseudotetrasauropus bipedoida*,
*Pentasauropus incredibilis*, *Sauropodopus antiquus*, *Trisauropodiscus aviforma*,
*Bosiutrisauropus phuthiatsani*, *Grallator socialis*, *Comptichnus moorosi*。
動物として描かない。乾いた泥の上の足跡として描くのは可で、この世界にはむしろ似合う。

## 描く前の確認（次に絵を追加するとき）

1. その学名が `public/data/gates/<id>.json` の `cast` にあるか
2. **その学名が何なのか**（PBDBの `phl` / `cll` / `fml`）。classだけを信じない
3. `flg` が `I`（足跡）や `F`（卵・器官）でないか。名前が *-opus* / *-pus* / *-podus* /
   *-ichnus* / *-oolithus* で終わるものは、フラグが立っていなくても足跡や卵のことが多い
