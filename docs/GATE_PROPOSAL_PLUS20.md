# ゲート +20 提言書

現在30ゲート / 12帯 / 孤立帯ゼロ / 両方つながる 16。
この20を足すと **50ゲート / 19帯 / 孤立帯ゼロ**、4時代ハブが3つになる。

GPT案を土台にして、**全項目をPBDBで実測**し、引けないもの・孤立するものを差し替えた。
数字はすべて「年代の窓で絞ったあとの地点数 / 学名まで付いた種数」。

判定の目安：◎ = 15地点以上かつ15種以上 / ○ = 8地点10種以上 / △ = それ未満 / ✗ = 作れない

## 2. 95 Maが4大陸そろう

GPTの言う「ひとつの時代、四つの大地」は、**新しい帯ゼロで成立する**。

```
95 Ma  ケムケム（アフリカ）      大河とデルタ、大型の捕食者
       西部内陸海路（北米）      大陸を割った海
       ウインクル（南米）        巨大竜脚類の陸
       ウィントン（オセアニア）   南方の河川
```

同じ地球儀を回して4大陸。実績にそのまま使える。

同じことが 190 Ma でも立つ（北米の陸 / 欧州の海 / アフリカの陸）。
250 Ma も3つになる（南アフリカ / 北米 / 中国）。

## 5b. 追補：実測でわかった3つの訂正

初版のあと、GPTの指摘を受けて3点を測り直した。**3点とも指摘が正しかった。**

### ① ハブは「同じ場所」ではなく「同じ地域」

ハブ内の最大距離（現在の座標）：

```
シーモア島      8 km   ← 本当に同じ島
イングランド    65 km   （ウェンロック追加後 222 km）
モロッコ      169 km
カルー        419 km   （クラレンス追加後 509 km）
コロラド高原   437 km
中国        2437 km   ← 澄江と熱河
```

**初版の「カルー：同じ丘で世界が一度死んで作り直される」は509 kmで、明確に言い過ぎ。撤回する。**

そして**中国の2,437 kmは地域ですらない**（東京〜香港に相当）。

- **中国ハブを割ることを提案する。** 澄江＋羅平（**162 km**・雲南）で1つのハブ、熱河（遼寧）は別のハブ。
  偽のハブが1つ消えて、本物のハブが1つできる。
- 用語は「同じ現在地域から入れる、時間の縦穴」に統一する。UIの文言も「場所」→「地域」。
- **言葉を選ぶのではなく距離を測って言葉を決める。** `gates:map` にハブの広がりを出させ、
  たとえば200 km未満を「同じ場所」、それ以上を「同じ地域」と機械的に呼び分ける。
  上位実績「同じ地面の下へ」は、シーモア島・モロッコ・雲南だけが取れる本物になる。

### ② シルル紀の帯は430 Maではなく425 Maに置く

```
Much Wenlock  中央 429.8 Ma
Bertie        中央 421.2 Ma
```

430 Ma帯だとズレが 0.2 と 8.8 で、**2つのゲートどうしが8.6 Myr離れる**。
425 Ma帯なら 4.8 と 3.8 に収まる。Scoteseの配布に425 Maはある。

実績の文言は「同じ時代」ではなく**「同じ年代帯」**にしておく（GPTの結論に同意）。

### ③ ナラクーテとラ・ブレアは3万年前ではない

年代の窓を変えて測り直した結果：

```
ナラクーテ  窓 0.06–0.005 Ma →  0地点  0種   ← 3万年前で切ると消える
            窓 0.2 –0.01  Ma →  4地点 62種   （範囲 0.065–0.070）
            窓 0.5 –0.005 Ma → 10地点 85種   （範囲 0.065–0.452、中央 0.393）

ラ・ブレア   窓 0.06–0.005 Ma →  1地点  0種
            窓 0.2 –0.005 Ma → 46地点568種   （範囲 0.006–0.112、中央 0.112）
```

**PBDBのナラクーテは6.5万〜45万年前、ラ・ブレアは中央11万年前。**
なので更新世の帯は **0.03 Ma ではなく 0.1 Ma** に置く。

「たった3万年前」は「たった十数万年前」になるが、驚きはほとんど変わらず、
**記録が言っていることと一致する**。

### ④ 追加：0 Ma付近の帯は地形が現代そのものになる

これはGPTも初版も触れていない問題。

Scoteseの0 Ma図は**今の地球**なので、更新世のゲートに入っても
**ハブと同じ地球儀が出る**。縦に潜った感じがゼロになる。

ただしこれは直せる。**氷期の海面は現在より約120 m低い。**
同じDEMを海面 −120 m で描き直せば、**ベーリンジア・ドッガーランド・サフルが陸として現れる**。
データは同じで、しきい値だけが違う。「氷期の海面（現在より約120 m低い）」と明記すれば
誰の解釈かも言える。

510 Maまで潜れる装置の最後に、**地図がほとんど今なのに大陸が繋がっている**地球が来る。
更新世ゲートの見どころは、たぶんこれになる。

## 6. 守っている規則

この装置には測って決めた規則が2つある。20の構成はどちらも満たしている。

**① 帯にひとり残さない。**
ゲートが自分の帯にひとりだと、その地球に入っても回す先に誰もいない。
新しい7帯はすべて2人以上。**追加後も孤立帯ゼロ。**

**② 帯は1つの瞬間より広く取る。上限の目安は15 Myr。**
地形は帯ごとに1枚なので、ゲートは自分の年代とずれた地球に立つ。
今回の最大ズレは Crato の14 Myr（130 Ma帯）。次いで Djadokhta の8 Myr。

`npm run gates:map` が孤立とズレを両方出すので、定義したら走らせて確認できる。

## 7. かかるもの

- **新しい地形テクスチャ7枚**（425 / 190 / 165 / 60 / 30 / 15 / 0.1 Ma）
  Scoteseの配布は0–540 Maを5 Myr刻みなので全部ある。ただし**385 Maのように欠番がある**ので、
  帯の年代は配布にある値へ寄せること（前回デボン紀を385→380にした）
- **絵20枚**（生成 + 記録との照合）
- 既存帯に入る5ゲートは**地形の追加なし**

## 8. 実績の判定について（別件）

現在の実装を読んだ結果：

```
same-place  「同じ現在地域で、異なる時代」  → gate.currentRegion（大陸単位）で判定
time-well   「時間の井戸」（3時代）         → 同じく currentRegion
```

ケムケム → マエヴァラノ（**約6,000 km離れている**）が「同じ場所」として数えられる。
ただし説明文には「同じ現在地域」と書いてあるので、実装は説明と一致している。
バグというより設計の選択。

**提案は「hubに直す」ではなく2段にすること。**

| 実績 | 判定 | 難易度 |
|---|---|---|
| 同じ大陸で、違う時代 | `currentRegion` | 入口。いまのまま |
| **同じ場所で、違う時代** | `hub` | モロッコ・コロラド・カルー・シーモア・中国・イングランドでのみ |
| **時間の井戸（3時代）** | `hub` | 追加後はコロラド(4) / カルー(4) / イングランド(4) / モロッコ(3) / 中国(3) だけ |

`currentRegion` 版を消すと、21ハブ中6つでしか進まない実績になって窮屈になる。
両方あると「大陸を旅する」と「同じ地面を掘り下げる」が別の遊びとして立つ。
