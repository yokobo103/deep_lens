# Deep Lens アイコン仕様

2026-09-05 起案。アセット制作に渡すための簡易設計。

## この装置でアイコンが担っていること

Deep Lensは、地球を触ったときに**時代を移動しても同じ場所・同じ生き物を見失わない**ことで成り立っている。
時代を送ると、生きた姿がその場で残り方に変わる（ドリフト）。

だからアイコンは「古代の生き物一覧」と「化石の一覧」の**2つの体系ではない**。
**1つのものが、2つの姿を持つ。** 対応表が仕様の中心。

もう1つの制約は憲章から来る。**凡例を読ませない。**
「まず見る → 気になる → それから読む」の順番なので、凡例を見ないと意味が分からない記号は失格。

## いま壊れていること（作り直す理由）

- 17記録のうち**10件が2つの絵柄に集中**。Spinosaurus と竜脚類が同じ🦕、獣脚類5種が全部同じ🦖
- 17個のうち**8個が活字記号**（✣ ≋ ⌁ ♠ ◇ ≈ ◢ ◒）で、絵文字6個と混在。2つの体系が同居している
- **現代側は4地域すべて同じ🦴**。だがPBDBの記録では、アメリカ（グリーンホーン）はサメ235・二枚貝148・アンモナイト114で、骨はほぼ出ない。骨アイコンは省略ではなく事実と食い違っている

## 3つの層

### 層1 — 地域マーカー（4個）

| `world-river` | 川・湖・湿地 | `#97c459` |
| `world-dryland` | 乾いた内陸 | `#ef9f27` |

### 層3 — 残り方（現代側・6個）

同じものが、いま何として残っているか。**PBDBの `cll`（分類）と `tpm`（保存様式）から機械的に決まる**ので、創作ではない。

| id | 残り方 | 由来する生き物 |
|---|---|---|
| `trace-bone` | 骨 | 獣脚類・スピノサウルス類・竜脚類・鳥脚類・ワニ形類・翼竜・硬骨魚 |
| `trace-tooth` | 歯 | サメ・エイ |
| `trace-coiled-shell` | 巻いた殻 | アンモナイト |
| `trace-bivalve-shell` | 二枚の殻 | 二枚貝 |

| `trace-footprint` | 足跡 | `tpm` に `trace` / `cast` を含む記録 |

**サメが「歯」になるのは事実。** グリーンホーンのサメ記録235件はほぼ歯で、
「サメは歯しか残らない」こと自体が、触って気づける発見になる。

足跡はケムケムに5件、圧痕はウィントンに6件、実際に記録がある。

## 対の作り方（ここが一番大事）

現代側の形は、**古代側の同じ個体から取れる部位**にする。別々にデザインしない。

- `life-theropod` → `trace-bone` は、その獣脚類の**大腿骨**
- `life-sauropod` → `trace-bone` は、その竜脚類の**首の椎骨**
- `life-ammonite` → `trace-coiled-shell` は、生きた個体の**殻そのもの**
- `life-conifer` → `trace-leaf-impression` は、その木の**枝葉が岩に押された跡**

ドリフトの最中に前者から後者へ形が変わるので、**シルエットの重心と大きさが揃っていること**。
片方が画面を埋め、片方が点になると、変化ではなく入れ替えに見える。

## 作りの規格

短くする。細かい規則を積むほど質が落ちるので、締めるのは上位カテゴリだけにする。

- **単色シルエット、塗りのみ。** 線画にしない。`fill="currentColor"` 固定で、色はCSS側で当てる
- **`viewBox="0 0 24 24"`。** 表示は22〜30px
- **図形が枠の80%以上を占めること。** 余白の割合ではなく、占有率で見る（小さく出る事故が起きる）
- **最も細い部分が0.9単位（≒1px）を下回らない。** 22pxに縮めた瞬間に消える
- **生き物はすべて左向き。** 例外を作らない
- グラデーション・影・テキスト・複数色は使わない。`<path>` だけ
- 1ファイル1アイコン。`icons/world/sea.svg` `icons/life/theropod.svg` `icons/trace/bone.svg`

## 合否の見かた

**凡例を隠して、全部22pxに縮めて、実際の地球の背景（濃い青緑と砂色）の上に並べる。**
そのとき、どれがどれか言えるかどうかだけで判定する。文章の説明を読ませない。

判定は1案ずつの合否ではなく、**並べて選ぶ**。却下したものは理由を添えて残し、次の生成に効かせる。

なので**各アイコンを1案に絞らず、少なくとも2つの方向で全セットを作る**こと。
（例：厚みのある塊のシルエット／細身で特徴を強調したシルエット）
