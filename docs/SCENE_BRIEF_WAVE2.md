## 1. Kayenta カイエンタ

- **タイトル**: `Kayenta` / 約192 Ma / **古緯度 21.2N**（亜熱帯） / 陸・季節河川
- **一言**: 砂漠のふちの、季節ごとに流れる川
- **同じ時代に**：ポシドニア（欧州の黒い海）・クラレンス（南アの乾いた高地）がある

**PBDBの分類が壊れている行**: *Kayentatherium* と *Dinnebitodon* の綱が `Osteichthyes`（硬骨魚）だが、
科は `Tritylodontidae` で**単弓類（哺乳類につながる系統）**。魚として描かない。

| 学名 | 何か | どこに |
|---|---|---|
| *Dilophosaurus wetherilli* | **ディロフォサウルス**。頭に2枚の薄い冠。**襟飾りも毒も無い**（映画のものは創作） | 陸 |
| *Scutellosaurus lawleri* | 小型の装盾類。背に小さな骨板が並ぶ二足の草食。この層で最多（17件） | 陸 |
| *Sarahsaurus aurifontanalis* | 初期の竜脚形類。四足寄りで、まだ小さい | 陸 |
| *Kayentatherium wellesi* | **トリティロドン科の単弓類**。ずんぐりした毛のある四足獣 | 陸 |
| *Eocaecilia micropodia* | **無足類（アシナシイモリ）の初期種**。細長く、退化した小さな四肢 | 湿った地面 |

## 2. Posidonia Shale ポシドニア頁岩

- **タイトル**: `Posidonia Shale` / 約183 Ma / **古緯度 38.7N** / **沖合の海**
- **一言**: 底に酸素のない、静かな黒い海
- **構図**：水中が主。**海底は黒い泥で、底生生物がいない**（無酸素）。落ちてきたものがそのまま残る

**注意**: 魚竜（*Stenopterygius*）で有名だが、**記録の上位14種には入っていない**。
上位はアンモナイトと魚。そちらを主役にする。

|---|---|---|

| *Dactylioceras athleticum* | アンモナイト。太い肋が密に並ぶ | 水中 |
| *Saurorhynchus hauffi* | 槍のように細長い魚（サウリクティス科）。長い吻。この層で最多（9件） | 水中 |

## 3. Clarens クラレンス

- **タイトル**: `Clarens` / 約190 Ma / **古緯度 -41.5N** / 陸・砂丘
- **一言**: 砂に埋もれていく、乾いた高地
- **カルーの4番目の時代**：ボーフォート(257) → カットバーグ(249) → エリオット(214) → **クラレンス(190)**

**この層は足跡の産地。** 上位14種のうち**10種が足跡の学名**で、体化石は4種しかない。
だから**描くのは4種**でよい。足跡は砂の上の足跡として描くのが、この場所として正しい。

**描いてはいけない（すべて足跡）**: *Grallator morijensis* / *Grallator lambereshei* /
*Batrachopus pilosus* / *Batrachopodiscus quthingensis* / *Lehahichnus coquinaris* /
*Sauroeidepus quthingensis* / *Qomoqomosauropus acutus* / *Kalosauropus pollex* /
*Cridotrisauropus cruentus* / *Kainomoyenisauropus ranivorus*

| 学名 | 何か | どこに |
|---|---|---|
| *Massospondylus carinatus* | 初期の竜脚形類。細い首、二足と四足を切り替える。この層で最多 | 陸 |
| *Heterodontosaurus tucki* | **ヘテロドントサウルス**。小型の鳥盤類で、**牙のような犬歯**を持つ | 陸 |
| *Notochampsa istedana* | 初期のワニ形類。陸を歩くタイプで、脚が長い | 陸 |

## 5. Nacimiento ナシミエント

- **タイトル**: `Nacimiento` / 約63 Ma / **古緯度 42.7N** / 陸・氾濫原

## 6. Rancho La Brea ランチョ・ラ・ブレア

- **タイトル**: `Rancho La Brea` / 約10万年前 / **緯度 34.0N**（10万年では大陸は動かないので現在地のまま） / **天然アスファルト**（tar 23件）
- **一言**: 天然のアスファルトに沈んだ、氷期の獣たち
- **構図**：黒く粘る池と、その縁。**沈みかけたものに鳥が群がる**のがこの場所の姿

### ⚠ サーベルタイガーを描かないこと

**PBDBのこの記録568種に *Smilodon* は1件も無い。**
ラ・ブレアといえばスミロドンだが、この装置は記録から世界を立てるので、描くと嘘になる。
**ダイアウルフ（*Aenocyon dirus*）は記録にある**ので、そちらを捕食者にする。

| *Mammuthus columbi* | **コロンビアマンモス**。毛は薄く、長く湾曲した牙 | 遠景・沈みかけ |

## 7. Naracoorte ナラクーテ

- **タイトル**: `Naracoorte` / 約30万年前 / **緯度 -37.0N**（同上） / **洞窟**（cave 9件）
- **一言**: 洞窟に落ちて残った、巨大な有袋類
- **構図**：**上から光が差し込む縦穴**と、その底。落ちた動物が積み重なる場所

**この記録の面白いところ**：85種の上位は *Perameles gunnii*・*Trichosurus vulpecula* など
**いまも生きているオーストラリアの動物**で、そこに絶滅した巨大種と
**1936年に絶滅したばかりのフクロオオカミ**が混ざる。「ついこの間まで違う地球だった」が、
これ以上ないかたちで出ている。

| 学名 | 何か | どこに |
|---|---|---|
| *Thylacoleo carnifex* | **フクロライオン**。有袋類の頂点捕食者。巨大な切断歯と親指の大きな鉤爪 | 底・岩の上 |
| *Thylacinus cynocephalus* | **フクロオオカミ（タスマニアタイガー）**。イヌに似た体、背から尾に縞 | 底 |
| *Procoptodon browneorum* | **ショートフェイスカンガルー**。顔が短く、指が1本 | 縦穴の下 |
| *Zygomaturus trilobus* | ディプロトドン類。カバのようにずんぐりした大型有袋類 | 底 |
| *Simosthenurus occidentalis* | ステヌルス類のカンガルー。がっしりして、木の葉を食べた | 底 |

## 描く前の確認

1. その学名が `public/data/gates/<id>.json` の `cast` にあるか。
   **無い場合は記録本体（`npm run verify:scenes` が引くのと同じ範囲）にあるか**
2. **その学名が何なのか**（PBDBの `phl` / `cll` / `fml`）。**綱だけを信じない**
3. `flg` が `I`（足跡）や `F`（卵・器官・花粉）でないか。
   名前が *-opus* / *-podus* / *-ichnus* / *-sauropus* / *-oolithus* で終わるものは、
   フラグが無くても足跡のことが多い
4. 植生がその年代に存在するか
