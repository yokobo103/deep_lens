# 想像図ラベル・ハイライト横展開手順

## 目的と変更範囲

「遭遇した生物」の学名を押したとき、同じ学名が印字された想像図上の位置へ静かに視線を導く。
通常の横展開で変更するのは `src/data/sceneHighlights.ts` の座標だけ。UI、演出、画像、
`drawn.ts`、Earth Lensは変更しない。

1ゲートずつ完成させる。1種だけ、または推測した座標を含むゲートは登録しない。

## 座標の定義

- 指す対象は生物の体ではなく、**画像に印字された学名ラベルの中央**。
- `x` は画像左端を0、右端を1とした位置。
- `y` は画像上端を0、下端を1とした位置。
- CSSで切り抜かれた表示ではなく、元画像全体を基準にする。
- キーは画像の綴りを転記せず、`src/data/drawn.ts` の学名をそのまま使う。
- ラベルが端にある場合、ラベルの範囲内で少し内側へ寄せてよい。別の対象を指すほど動かさない。

## 座標を採る

1. `npm run dev` を起動する。
2. 次のURLを開く（開発環境でだけ有効）。

   ```text
   http://localhost:5173/?scene-highlight-lab=<gate-id>
   ```

3. 右側の学名を1つ選ぶ。
4. 画像に印字された同じ学名の中央をクリックする。
5. 5種すべてについて繰り返す。クリック後は次の種が自動選択される。
6. 番号付きマーカーが正しいラベルに重なっていることを目で確認する。
7. 下部に出たブロックを `SCENE_HIGHLIGHTS` へ追加する。

ラボはファイルを自動更新しない。誤クリックが即座にソースへ混ざらないための意図的な二段階である。

## 推測せず止める条件

次のどれかに当たったら、そのゲートは追加せず、画像・ゲートID・該当学名を所長へ差し出す。

- 学名ラベルが無い、読めない、または2か所以上あって一意に決まらない。
- 画像上の綴りと `drawn.ts` が異なり、同じ生物だと確認できない。
- リストの生物と画像の対応に確信が持てない。
- 端や拡大ボタンに近すぎて、正しい位置を指しながらリングを見せられない。
- 画像自体を直したくなった。座標追加と画像修正は別作業にする。

## 自動検査

```text
npm run verify:highlights
npm run lint
npm run typecheck
npm run verify:separation
npm run build
```

`verify:highlights` は、登録した各ゲートについて以下を検査する。ビルドからも自動実行される。

- `drawn.ts` の全種に座標がある。
- 余分な種、重複、順序違いがない。
- `x` と `y` が0〜1の内側にある。
- 対応する想像図ファイルがある。

## 実ブラウザQA

座標を登録した各ゲートを通常のDeep Lensから開き、全種を1回ずつ押す。

- リストで押した種と、光る学名が一致する。
- 明るい空・暗い水中や地面のどちらでもリングが見える。
- リングが画像端で不自然に欠けない。
- 右下の拡大ボタンや「想像図」表示を隠さない。
- 約3秒後に自然に消え、連続タップでも選んだ種へ移る。
- PC幅とスマートフォン幅の両方で確認する。
- ブラウザの警告・エラーがない。

## エージェントへ渡す単位

一度に3〜5ゲートまで。各バッチで座標採取、自動検査、実ブラウザQAを完了してから次へ進む。
通常のバッチでは `sceneHighlights.ts` 以外に差分が出たら止め、理由を確認する。

完了報告には、対応したゲートID、判断を保留したゲート、検査結果を必ず含める。
