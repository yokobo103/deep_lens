# 第3波 8ゲートの絵 — 生成用の材料

既存42枚と同じ体裁。学名はすべてPBDBの記録と照合済み（`npm run verify:scenes` 通過）。

これで **50ゲート / 19帯 / 孤立帯ゼロ**。4時代ハブが3つ。

**イングランドが4時代になりました。425 → 163 → 132 → 52 Ma。**
4地点は互いに **227 km** の中にあって、**3億7,700万年**をまたぎます。この装置でいちばん深い縦穴です。

---

## 共通（既存42枚と揃える）

- 横長（16:9前後）。左上にゲート名を英語で1行、細い罫線
- 学名はイタリックで対象のそばに。**日本語や説明文は焼き込まない**
- 下部の解説帯は入れない
- 水がある世界は水面で上下に割る構図
- 光は古緯度に合わせる

## 1. Much Wenlock ウェンロック

- **タイトル**: `Much Wenlock` / 約430 Ma / **古緯度 -23.9N**（南半球の亜熱帯） / 炭酸塩の礁
- **一言**: 赤道の南にあった、サンゴとウミユリの礁
- **イングランドの1番目の時代**：**425** → 163 → 132 → 52 Ma

### ⚠ 記録の上位6種は描けない

**上位14種のうち6種がコノドント**（*Panderodus* / *Wurmiella* / *Ozarkodina* /
*Pseudooneotodus* / *Oulodus*）。コノドントは**体長数cmのウナギ状動物**で、
化石として残るのは**顕微鏡サイズの歯の要素だけ**。礁の風景に描ける対象ではない。

**礁そのものは記録の下のほうにちゃんといる**ので、そちらを描く。

| 学名 | 何か | どこに |
|---|---|---|
| *Halysites catenularius* | **クサリサンゴ**。細い管が鎖状につながった群体 | 礁の底 |
| *Favosites gothlandicus* | **ハチノスサンゴ**。六角形の管が蜂の巣状に密集した塊 | 礁の底 |
| *Calymene blumenbachii* | **三葉虫**。ウェンロックの名物（英国で「ダドリー・ロカスト」と呼ばれた種） | 礁の底を歩く |
| *Crotalocrinites rugosus* | **ウミユリ**。長い茎の先に網状に広がった腕 | 礁の上に立つ |
| *Atrypa reticularis* | 腕足類。丸い二枚の殻。この層の腕足類で最多（7件） | 礁の底 |

**イギリスが南半球にあった時代。**光と水の色は熱帯の浅い海として。

## 2. Bertie バーティー

- **タイトル**: `Bertie` / 約421 Ma / **古緯度 -30.5N** / **塩の濃い潟**（lagoonal/restricted 9件）
- **一言**: 塩の濃い潟に集まった、巨大なウミサソリ
- **同じ時代に**：ウェンロック（英・生命に満ちた礁）がある。**こちらは生きものの種類が少ない**
  （記録は23種だけ）。塩が濃すぎて、耐えられるものしかいない潟

| 学名 | 何か | どこに |
|---|---|---|
| *Acutiramus macrophthalmus* | **大型のウミサソリ**。全長2 m級。前肢に鋸歯のある大きなハサミ | 水底 |
| *Eurypterus remipes* | **ウミサソリ**。この産地の代表種。平たい体、櫂状の後肢 | 水底・群れ |
| *Dolichopterus herkimerensis* | ウミサソリ。細身で、櫂が大きい | 水底 |
| *Proscorpius osborni* | **最古級のサソリ**。この層で最多（9件）。小型 | 浅瀬 |
| *Pyrgocystis batheri* | ウミリンゴ類（棘皮動物）。筒状で海底に付着 | 底に付着 |

**注意**: *Proscorpius* をPBDBは `terrestrial`（陸生）と記録しているが、

## 3. Oxford Clay オックスフォード粘土

- **タイトル**: `Oxford Clay` / 約163 Ma / **古緯度 42.0N** / **沖合の海**（offshore 31件）
- **一言**: 首長竜と魚竜がすれちがう、泥の海
- **イングランドの2番目**：425 → **163** → 132 → 52 Ma
- **罠なし。**この波でいちばん素直なゲート。海生爬虫類が上位14種に勢ぞろいしている

**5種すべて体の形がちがう**ので、そこを見せる構図に。

| 学名 | 何か | どこに |
|---|---|---|
| *Liopleurodon ferox* | **リオプレウロドン**。首が短く頭が巨大な首長竜（プリオサウルス類）。頂点捕食者 | 水中・主役 |
| *Cryptoclidus eurymerus* | **首の長い首長竜**。小さな頭、4枚のひれ | 水中 |
| *Ophthalmosaurus icenicus* | **魚竜**。イルカ型で、**目が異常に大きい**（名前の由来） | 水中 |
| *Metriorhynchus brachyrhynchus* | **完全に海に適応したワニ**。鱗甲がなく、尾びれがある | 水中 |
| *Leedsichthys problematicus* | **史上最大の硬骨魚**（推定16 m級）。プランクトン食で口を開けて泳ぐ | 遠景・巨大 |

## 4. Daohugou 道虎溝

- **タイトル**: `Daohugou` / 約160 Ma / **古緯度 42.8N** / **大きな湖**（lacustrine - large 47件）
- **一言**: 無数の昆虫と、木から木へ滑空する獣の湖
- **遼寧ハブの1番目**：**160** → 123 Ma。2地点は **57 km しか離れていない**。
  この装置でシーモア島（8 km）に次いで近いハブ

### 記録の874種のうち854種が昆虫

クラトと同じ構図。ただし**この場所が有名な理由は、残りの17種の脊椎動物**のほうで、
それが全部そろっている（各1〜2件）。**昆虫は1種だけ代表として描く。**

**PBDBの分類が壊れている行**: *Castorocauda* と *Agilodocodon* の綱が
`Osteichthyes`（硬骨魚）。実際は**哺乳形類**（哺乳類の一歩手前の系統）。魚として描かない。

| 学名 | 何か | どこに |
|---|---|---|
| *Epidexipteryx hui* | **エピデクシプテリクス**。ハト大の羽毛恐竜。**尾から4本の長いリボン状の飾り羽**。飛べない | 木の枝 |
| *Volaticotherium antiquus* | **滑空する哺乳形類**。四肢のあいだに飛膜。ムササビ的だが哺乳類ではない | 木から木へ滑空 |
| *Castorocauda lutrasimilis* | **泳ぐ哺乳形類**。**ビーバーのような平たい鱗の尾**、水かき、カワウソ型 | 水辺・水中 |
| *Jeholopterus ningchengensis* | **毛の生えた小型翼竜**（アヌログナトゥス科）。**顔が短く、目が大きい**。虫を捕る | 空・夕暮れ |
| *Allaboilus gigantus* | 大型のキリギリス類。この層の昆虫で最多（6件） | 草・葉の上 |

## 5. Fayum ファイユーム

- **タイトル**: `Fayum` / 約31 Ma / **古緯度 26.2N** / **川**（fluvial 21件）
- **一言**: サハラになる前の、川と森
- **いまは砂漠**。同じ場所が緑だったことが、この絵の全部

**上位14種は小型のハイラックス類と齧歯類**だが、**この場所の顔は記録の下にいる**。
以下の5種はすべて記録本体で確認済み。

**PBDBのフラグが壊れている行**: *Bothriogenys fraasi* に `F`（卵・器官などの形態タクソン）
フラグが立っているが、これは**アントラコテリウム類（カバに近い哺乳類）の実体**。
アプリ上は「足跡・卵」の欄に出てしまう。描く5種には入れていない。

| 学名 | 何か | どこに |
|---|---|---|
| *Aegyptopithecus zeuxis* | **エジプトピテクス**。ネコ大の初期の狭鼻猿。**ヒトにつながる系統の初期の姿** | 木の上 |
| *Apidium phiomense* | 小型の初期霊長類。リスほど。この層の霊長類で最多 | 木の上 |
| *Arsinoitherium zitteli* | **アルシノイテリウム**。サイ大の獣で、**鼻の上に巨大な角が2本、並んで生える** | 川辺 |
| *Moeritherium lyonsi* | **メリテリウム**。初期のゾウの仲間だが、**バクのように低く、水辺で暮らす**。鼻はまだ短い | 水中・水辺 |
| *Titanohyrax angustidens* | **巨大なハイラックス**。いまのハイラックスはウサギ大だが、これはずっと大きい | 陸 |

## 6. Hsanda Gol フサンダゴル

- **タイトル**: `Hsanda Gol` / 約31 Ma / **古緯度 46.6N** / **陸**（terrestrial 87件）
- **一言**: アジアの内陸が乾きはじめた、赤い平原
- **同じ時代に**：ファイユーム（エジプト・川と森）がある。**乾いた側と湿った側**

### この記録は、ほぼ全部が齧歯類

上位14種のうち**13種がネズミ・ハムスター・トビネズミ・ウサギの仲間**。
草原に小さな穴掘りが無数にいる世界というのが、記録が言っていること。
そこに**史上最大の陸生哺乳類が1件だけ**入っている。

| 学名 | 何か | どこに |
|---|---|---|
| *Paraceratherium grangeri* | **パラケラテリウム**。**史上最大の陸生哺乳類**、肩高5 m級の角のないサイ。長い首 | 遠景・巨大 |
| *Hyaenodon gigas* | **ヒアエノドン**。大型の肉食獣（ヒアエノドン類、現生の肉食類とは別系統）。細長い頭 | 陸 |
| *Tsaganomys altaicus* | 穴を掘る大型の齧歯類。この層で3番目に多い（20件） | 巣穴のそば |
| *Desmatolagus gobiensis* | **初期のウサギ**。耳はまだ短い（18件） | 陸 |
| *Cricetops dormitor* | ハムスターの仲間。ずんぐりした小型齧歯類（11件） | 陸 |

**構図の提案**：手前に小さな齧歯類たちの世界、遠景にパラケラテリウム。
**大きさの落差そのものがこの絵の内容**になる。

## 8. La Venta ラ・ベンタ

- **タイトル**: `La Venta` / 約12 Ma / **古緯度 2.6N**（赤道直下） / 川と氾濫原（fluvial 45件）
- **一言**: 他の大陸から切り離されて育った、奇妙な獣たち
- **コロンビアハブの2番目**：59 → **12 Ma**。**ただし2地点は920 km離れている**
  （セレホンは北端のカリブ海側、ラ・ベンタはアンデスのマグダレナ渓谷）。
  カルー（429 km）より遠く、この装置でいちばん広いハブ

**南米が島大陸だった時代。**北米とつながる300万年前より前なので、
**ウマもシカもネコもイヌもいない。**空いた席を、南米だけの系統が埋めている。

**PBDBのフラグが壊れている行**: *Miocochilius anomopodus* に `F` フラグ。
実体は**インテラテリウム科の有蹄類**。描く5種には入れていない。

## 描く前の確認

1. その学名が `public/data/gates/<id>.json` の `cast` にあるか。
   **無い場合は記録本体（`npm run verify:scenes` が引くのと同じ範囲）にあるか**
2. **その学名が何なのか**（PBDBの `phl` / `cll` / `fml`）。**綱だけを信じない**
   （今回も *Castorocauda* / *Agilodocodon* が「硬骨魚」と書かれていた）
3. `flg` が `I`（足跡）や `F`（卵・器官・花粉）でないか。
   **ただし今回は逆の間違いもあった**：*Bothriogenys* と *Miocochilius* は
   実在の哺乳類なのに `F` が立っている。**フラグも人が付けたもので、間違うことがある**
4. その生きものが**化石として何が残っているか**。
   コノドントは顕微鏡サイズの歯しか残らないので、風景の中の生きものとしては描けない
5. 植生がその年代に存在するか
