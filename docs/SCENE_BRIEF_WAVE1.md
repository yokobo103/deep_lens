# 第1波 5ゲートの絵 — 生成用の材料

既存30枚と同じ体裁。学名はすべてPBDBの記録と照合済み。

**今回の罠は4つ。** どれも綱だけ見ていると踏む。

1. **Winton の *Wintonopus latomorum* は足跡**（-opus）。PBDBはフラグを立てていないので、名前で見分けるしかない
2. **Winton の *Araucaria mesozoica* の門が `Equisetophyta`（トクサ類）**。実際は科が `Araucariaceae` で**針葉樹**。トクサとして描かない
3. **Huincul の上位14種のうち4種が花粉・胞子**（*Cretacaeiporites* / *Equisetosporites* / *Fraxinoipollenites* / *Elateroplicites*）。生きものとして描かない
4. **Djadokhta の *Elongatoolithus frustrabilis* は卵**（PBDBのフラグあり）。巣の卵として描くのは可、動物として描くのは不可

---

## 共通（既存30枚と揃える）

- 横長（16:9前後）。左上にゲート名を英語で1行、細い罫線
- 学名はイタリックで対象のそばに。**日本語や説明文は焼き込まない**
- 下部の解説帯は入れない
- 水がある世界は水面で上下に割る構図
- 光は古緯度に合わせる
- **被子植物（花・広葉樹）は白亜紀から。**今回は5ゲートとも白亜紀以降か三畳紀なので、
  白亜紀の3枚（Huincul / Winton / Crato）には初期の被子植物を少しだけ混ぜてよい。
  ただし**主役は針葉樹・ソテツ・イチョウ・シダ**

## 1. Huincul ウインクル

- **タイトル**: `Huincul` / 約96 Ma / **古緯度 -45.8N**（南半球中緯度） / 陸・河川
- **一言**: 巨大な竜脚類と、それを追う大型獣脚類の平原
- **同じ時代に**：ケムケム（アフリカ）・西部内陸海路（北米）・ウィントン（豪）がある。**南米の顔**として

| 学名 | 何か | どこに |
|---|---|---|
| *Argentinosaurus huinculensis* | **史上最大級の竜脚類**。全長30 m超。太い胴と長い首 | 陸 |
| *Mapusaurus roseae* | 大型の獣脚類（カルカロドントサウルス科）。群れで大型竜脚類を襲ったとされる | 陸 |
| *Skorpiovenator bustingorryi* | アベリサウルス科の獣脚類。**短く高い顔、極端に小さい前肢** | 陸 |
| *Limaysaurus tessonei* | 中型の竜脚類（レバッキサウルス科）。背に低い帆 | 陸 |
| *Sidersaura marae* | 同じくレバッキサウルス科の竜脚類 | 陸 |

**描いてはいけない**: *Cretacaeiporites* / *Equisetosporites* / *Fraxinoipollenites* / *Elateroplicites* は
**すべて花粉・胞子の学名**。植生として描くのは可だが、その名前を付けない。

## 2. Winton ウィントン

- **タイトル**: `Winton` / 約96 Ma / **古緯度 -52.5N**（かなり高緯度・冷涼） / 河川と氾濫原
- **一言**: 南の大陸を流れた、曲がりくねった川
- **植生**：ナンヨウスギ、イチョウ、シダ、ポドカルプス。**高緯度なので鬱蒼とした温帯林**

| 学名 | 何か | どこに |
|---|---|---|
| *Diamantinasaurus matildae* | 頑丈な体つきの竜脚類（ティタノサウルス類） | 陸 |
| *Wintonotitan wattsi* | 細身の竜脚類。この層で最多（7件） | 陸 |
| *Australovenator wintonensis* | **メガラプトル類の獣脚類**。細身で、前肢に大きな鉤爪 | 陸 |
| *Austrosequoia wintonensis* | **針葉樹**（スギ科）。球果 | 陸 |
| *Ginkgo wintonensis* | **イチョウ**。扇形の葉 | 陸 |

**描いてはいけない**: *Wintonopus latomorum* は**足跡**の学名。動物として描かない
（泥に残る鳥脚類の足跡として描くのは可）。
*Araucaria mesozoica* は**針葉樹（ナンヨウスギ）**で、PBDBが言うトクサ類ではない。

## 3. Djadokhta ジャドフタ

- **タイトル**: `Djadokhta` / 約78 Ma / **古緯度 40.8N** / **砂丘**（eolian 30件）
- **一言**: 砂丘と乾いた風
- **同じ時代に**：ネメグト（同じモンゴル、湿った河川）がある。**正反対の顔として描く**。
  水はほとんど無い。植生はまばらな低木のみ

| 学名 | 何か | どこに |
|---|---|---|
| *Protoceratops andrewsi* | **プロトケラトプス**。角のない小型角竜、大きな襟。この層で最多（17件） | 陸 |
| *Velociraptor mongoliensis* | **ヴェロキラプトル**。羽毛のある小型獣脚類、後肢に鉤爪。**七面鳥ほどの大きさ** | 陸 |
| *Pinacosaurus grangeri* | 鎧竜。装甲した背中と尾のこん棒 | 陸 |
| *Shuvuuia deserti* | アルヴァレスサウルス類。**鳥のような細い体、前肢が短く指が1本大きい**。羽毛あり | 陸 |
| *Zalambdalestes lechei* | **哺乳類**。長い吻と長い後肢の小型獣 | 陸 |

**描いてはいけない**: *Elongatoolithus frustrabilis* は**卵**の学名。巣の卵として描くのは可。

## 5. Crato クラト

- **タイトル**: `Crato` / 約116 Ma / **古緯度 -8.2N**（熱帯） / **大きな湖**（lacustrine 78件）
- **一言**: 静かな潟に沈んだ、無数の昆虫
- **記録は492種**で、**そのほとんどが昆虫**。グリーンリバーと同じ構図（上＝岸と空、下＝沈んでいく虫）

**注意**: クラトは翼竜でも有名だが、**記録の上位14種に翼竜は入っていない**。
主役は昆虫とサソリ。翼竜を主役にすると記録から外れる。

| 学名 | 何か | どこに |
|---|---|---|
| *Protoischnurus axelrodorum* | **サソリ**。保存が良く、体節までわかる | 岸 |
| *Cratoelcana zessini* | エルカナ科の直翅類（キリギリスに近い）。この層で最多（11件） | 岸・草の上 |
| *Gomphaeschnaoides obliquus* | **トンボ**。透明な翅 | 空・水面 |
| *Protoligoneuria limai* | **カゲロウ**。細い体と長い尾 | 空・水面 |
| *Ponopterix axelrodi* | ウメノコレア科の昆虫（ゴキブリに近い）。**樹上性** | 木の上 |

## 描く前の確認

1. その学名が `public/data/gates/<id>.json` の `cast` にあるか
2. **その学名が何なのか**（PBDBの `phl` / `cll` / `fml`）。**綱だけを信じない**
3. `flg` が `I`（足跡）や `F`（卵・器官・花粉）でないか。
   名前が *-opus* / *-podus* / *-ichnus* / *-oolithus* / *-pollenites* / *-sporites* で終わるものは、
   フラグが無くても足跡・卵・花粉のことが多い
4. 植生がその年代に存在するか
