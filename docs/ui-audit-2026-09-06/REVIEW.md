# Deep Lens UI・人間工学レビュー

初回観察: 2026-09-06 / 最新実装との照合: 2026-09-07

## 結論

探索の基本構成は良い。ただし、初めて使う一般の人にとって「わかりやすく使いやすい」とはまだ言い切れない。特に、小さい文字、近接する地名の重なり、読了後に消える閉じる操作が、読む・選ぶ・探索へ戻る負担を増やしている。

地球を主役にし、短い文脈から詳細へ進む方針は維持する。改善の中心は情報量を増やすことではなく、必要な情報と操作を見える場所・読める大きさに置くこと。

## 範囲と方法

- ローカルの実装を起動し、日本語の初期画面、モロッコ→フェズアタ、年代選択、古代地球、生物一覧、拡大画像、現代への帰還、追加された探検ログを操作。
- PC: 初回1280×720、再開後1236×903。スマホ相当: 390×844 CSS px。実機タッチ試験ではなく、ブラウザの表示幅による検証。
- スクリーンショット、アクセシビリティツリー、DOMの文字サイズ・要素寸法、React/CSSを照合。
- 再開後の基準: HEAD `46dd51b` と、その時点の未コミット変更（About追加、ヘッダー調整等）。既存変更には手を加えていない。
- 評価終了時に別作業でHEADが `29602cb` へ進んだことを確認。追加画面を含めて観察したが、このレビューからコミット操作は行っていない。
- 実装・公開変更なし。実ユーザーを対象としたユーザビリティ試験、全ページ・全言語・全端末のWCAG適合監査ではない。

## 良い点

1. 地球が最初から見え、長い説明を読まずに場所を選べる。最初の情報負荷が低い。
2. 入口カードの「この世界に入る」は視覚的に強く、次の操作が明確。
3. 「極に近い、冷たい海の底」のような短文が、地名だけでは想像できない環境を補っている。
4. 「現代へ戻る」とパネルの「閉じる」を分けている。地球を見たいだけの人が時代を離れる必要がない。
5. スマホでは生物一覧を任意で開く構成になっている。詳細を常時読ませない方針は適切。
6. 探検ログは訪問先を記憶する負担を減らし、画像と地名から再訪できる。ログの「約4億7,700万年前」は年代を理解しやすい表現。

## 先に直したい点

### 1. 地名・年代・ボタンの文字が小さい（高）

**観察:** 地名ラベル8px、入口の年代8px、年代選択と主要ボタンの文字9px。スマホの生物一覧は学名11px、分類見出しと補足8px。地球の拡大操作ではHTMLの文字は大きくならない。

**人への影響:** 読むために目を近づける、何度も見直す負担が生じる。細かい文字を読めることが探索の前提になっている。

**改善案:** 主要操作と地名は12〜14px、本文は14〜16pxを初期案とし、画面上で調整する。これは設計上の提案でありWCAGが指定する最小文字サイズではない。地名の拡大は次項の重なり対策とセットで行う。背景が変わる地球上の補助文には安定した背景面を用意する。

**操作寸法:** 初回実測で地球マーカー34×34px、閉じる28×28px、言語ボタン34×21px、年表約38×20px。9/7にヘッダー寸法の変更があるため、初回数値を最新版の全ボタンへ適用しない。タッチ操作は44px程度の領域を設計目標にする。24px未満という寸法だけでWCAG不適合と断定せず、間隔・例外を含め確認する。

**該当:** `src/styles.css` の `.gate-marker__label`、`.gate-card__age`、`.gate-card__enter`、`.world-cast`、各ボタン。

### 2. 近い場所の入口が重なり、別々に読み取れない（高）

**観察:** PC・390px幅とも、初期のヨーロッパでシャルカとゾルンホーフェンのラベルが重なり、一部が隠れる。マーカーの円も重なる。9/7の最新版でも再現。

**人への影響:** 視覚的な探索が難しく、どの印がどの地名か対応づけにくい。拡大が必要だと気づかなければ、その場所を見落とす。

**改善案:** 密集時は「この周辺に3か所」とまとめ、選択すると拡大または小さな候補を開く。選択地点の名前を優先表示する。文字サイズを下げて解決しない。

**証拠:** `desktop-home-0907.png`、`mobile-home-0907.png`。`GateGlobe.tsx` は座標への配置と裏側の非表示を行うが、ラベル間の衝突は解消していない。

### 3. スマホで一覧を読むと「閉じる」「地球を見る」が隠れる（高）

**再現:** フェズアタに入る→「顔ぶれを見る」→一覧を下へスクロール。

**観察:** 両方の操作がパネルのスクロール領域外へ消える。画面上部に「現代へ戻る」は残るが、これは現在の時代から退出する別の操作。9/7にも再現。

**人への影響:** 読み終わった時に探索へ戻りにくい。閉じ方を記憶して逆スクロールする必要がある。

**改善案:** パネルのヘッダーかフッターを固定し、「地球を見る」または閉じる操作を常に1つ残す。パネル内容だけをスクロールする。

**証拠:** `mobile-world-0907.png` と `mobile-scrolled-0907.png`。`WorldPanel.tsx`、`.world-panel { overflow: auto }`、`.world-panel__close { position: absolute }`。

### 4. 初期の操作案内がCesiumロゴ・出典と重なる（高）

**観察:** 390×844の初期画面で「地球を回して、入り口を見つけよう」が下端のCesiumロゴと重なる。9/7にも再現。

**人への影響:** 初めて触る人に最も必要な案内が読みにくい。PCでも背景によって案内の見え方が変わる。

**改善案:** 出典の領域を確保した上で案内を上へ移す。「ドラッグで回す／印を選ぶ」など、操作と結果を短く伝える。初回操作後に控えめにできる。出典を消して解決しない。

**証拠:** `mobile-home-0907.png`。`.gate-hint` とCesiumのクレジット領域。

### 5. 拡大画面・探検ログのTab操作が背後へ抜ける（高）

**再現:** 画像を拡大→Tab。初回は背後の「約95 Ma ケムケム」にフォーカスが移った。9/7には探検ログを開く→Tabで背後の「この装置について」へ移ることを確認。

**人への影響:** 見えている画面とキーボードの操作先が一致せず、意図しない背景操作につながる。

**改善案:** 開いた時にダイアログ内へフォーカスを移し、開いている間は背景を操作対象から外す。閉じたら起点へ戻す。Escapeで閉じる既存機能は維持する。

**該当:** `GateScene.tsx`、`ExplorerLog.tsx`。`About.tsx` も同様の構造だが、今回About内のTab動作は未検証。

## 説明と探索のつながりを改善したい点

### 6. Maと年代目盛りの意味を利用者に推測させている（中）

入口と古代画面の「約475 Ma」は、単位を知らない人には読めない。年表には両端の年代や「現在」の可視ラベルがなく、光る印と目盛りの意味も説明されない。目盛りは表示用で操作できないが、時間を動かせそうな形でもある。

「約4億7,500万年前」を主表示にし、Maは補助にする。ログでは既に日本語の年代変換があるため、表現を揃えられる。ただしログは記録の中央値477 Ma、地球は地形の代表年代475 Maを使うので、単に同じ数値に上書きしない。「地球の復元年代」と「この地層の記録年代」の違いを必要な場所で短く説明する。

年表は「時代の位置」と明示し、両端に「約5.4億年前／現在」を置く案がある。クリックできないこと自体は欠陥ではない。操作できるように変更するかは別の設計判断。

### 7. 入口の「14種」と中の「62種」が別の意味なのに同じ総数に見える（中）

フェズアタで入口は「14種」、入った後は「記録されている62種のうち」。実データでは`cast`は表示用に抽出したリスト、`castTotal`は総数。`tools/build-gates.mjs` は`CAST_LIMIT`でリストを制限し、manifestの`cast`へその長さを出している。

入口を「代表14種」または「記録62種」にする。後者はmanifestへ総数を追加する必要がある。数値の意味を暗記・推理しなくて済むようにする。生物名横の数にも「記録数」という列見出しを置き、意味の説明を一覧の最下部だけに置かない。

### 8. 読み込みの失敗や待ち時間が画面に出ない（中・コード確認）

`GateHub.tsx` のmanifest・詳細読込失敗は`console.warn`のみ。`GateGlobe.tsx` の古地形読込失敗では地形レイヤーを落とすため、古代の年代表示のまま現代背景が残る経路がある。今回通信失敗の注入試験はしていない。

待機中・失敗・再試行を画面に示す。地形が準備できた状態と年代の表示を合わせ、復元できていない画面を古代として見せない。詳細データの遅延応答が別の選択に届く可能性もあるため、選択中IDとの照合を実装時に検証する。

### 9. 一般の人が次の発見へ進む手掛かりが弱い（中・評価仮説）

地名や学名だけでは「そこに何があるか」を予測しにくい。スマホの別時代ボタンは場所名が隠れ、「約95 Ma」だけになる。想像図は拡大できるが、可視テキストは「想像図」で、拡大できることはタッチでは伝わりにくい。

入口の選択時に短い環境表現、別時代ボタンに「約9500万年前・川の世界」、画像に小さな「拡大」を添える案がある。生物は既存の分類見出しを活かし、一般向けの呼び名が確かめられるものだけ補う。推測の和名は作らない。

## 改善順の提案

1. 文字と操作領域、地名の重なり、下端案内、固定の閉じる操作、ダイアログのフォーカスを整える。
2. 年代・数値・画像操作の表現を揃え、待機・失敗状態を明示する。
3. 初見の人に「入口を選ぶ→時代を変える→別の場所へ行く→一覧を閉じる→ログから再訪」を説明なしで試してもらう。完了可否、迷った箇所、誤操作、年代と記録数の理解を観察する。

これはUI内の改善順の提案であり、ラボ全体の優先順位や採用方針を決裁したものではない。

## 評価基準

- [Nielsen Norman Group: 10 Usability Heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/) — 状態の可視性、利用者の言葉との一致、記憶に頼らず見て分かる設計、操作の自由、エラーからの回復。
- [W3C: WCAG 2.2](https://www.w3.org/TR/WCAG22/) — キーボード操作、フォーカス、文字のコントラスト、対象サイズ。通常文字のコントラスト目標は4.5:1。対象サイズのAA基準は24×24 CSS px（間隔等の例外あり）、44×44は強化基準。今回、半透明背景を含む全要素のコントラストは測定していない。
