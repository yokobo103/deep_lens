# 新しい15ゲートの絵 — 生成用の材料

既存15枚と同じ体裁で作るための一式。学名はすべてPBDBの記録と照合済みで、
`npm run verify:scenes` が全75体を機械的に確認しています。

**今回はPBDBの分類が壊れている行が非常に多い。** 単弓類（哺乳類につながる系統）が
まとめて `Osteichthyes`（硬骨魚）に入っています。**綱を信じず、科と下の説明を読んでください。**

---

## 共通（既存15枚と揃える）

- 横長（16:9前後）。左上にゲート名を英語で1行、細い罫線
- 学名はイタリックで対象のそばに。**日本語や説明文は焼き込まない**
- 下部の解説帯は入れない
- 水がある世界は水面で上下に割る構図
- 光は古緯度に合わせる。**南極・カルーは高緯度＝低く柔らかい光**

### 植物の年代（前回ここを外しました）

- **被子植物（花・広葉樹・ヤシ・マングローブ）は白亜紀まで存在しません。**
- カンブリア〜デボン紀：**陸上に植物はほぼ無い**。岸は裸の岩と泥
- 石炭紀：リンボク（鱗木）、フウインボク、木生シダ、トクサ。**巨大だが花はない**
- ペルム〜三畳紀：*Glossopteris*（グロッソプテリス）、トクサ、シダ、針葉樹
- ジュラ〜白亜紀前期：針葉樹、ソテツ、ベネチテス類、イチョウ、シダ

## 描く前の確認（変更なし）

1. その学名が `public/data/gates/<id>.json` の `cast` にあるか
2. **その学名が何なのか**（PBDBの `phl` / `cll` / `fml`）。**綱だけを信じない**
3. `flg` が `I`（足跡）や `F`（卵・器官）でないか。名前が *-ichnus* / *-opus* / *-podus* /
   *-oolithus* で終わるものは、フラグが無くても足跡や卵のことが多い
4. **植生がその年代に存在するか**（上の「植物の年代」参照）
